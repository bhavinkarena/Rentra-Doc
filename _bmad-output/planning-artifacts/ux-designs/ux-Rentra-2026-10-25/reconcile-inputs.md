|---|---|
| Premium, trustworthy, relaxing, modern and simple | Existing emerald/champagne, warm light surfaces, local Plus Jakarta Sans and real Rentra identity preserved. |
| Improve only when better than existing | Incumbent comparisons, retained wizard/workspace patterns and explicit implementation checks; no wholesale replacement. |
| Guests can browse broadly and optionally filter farm/villa/hotel/apartment | Search/filter behavioral contract; written-only coverage accepted. |
| Photos first, details left and price right | Approved responsive hotel-room composition, with readable stacking at narrow width/zoom. |

| Share progress in Rentra-Doc | Canonical spines, mockups, reviews, decision log and HANDOFF updated together; no competing code-repository progress copies. |
